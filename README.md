# Health Monitor ETL & Data Visualization

This project focuses on the extraction, transformation, and loading (ETL) of general health data for an individual. The pipeline involves cleaning the data using **Power Query**, transforming it using **SSIS**, and storing it in a **SQL Server database (SSMS)**. Finally, **Power BI** is used to visualize the health status and insights.

## Project Overview

This ETL process provides a detailed health overview, including various metrics about an individual's health status. The data is processed, cleaned, and then loaded into a SQL Server database for further analysis and reporting. The final results are visualized using Power BI dashboards.

## Tools Used

- **Power Query**: Used for data cleaning and transformation.
- **SSIS (SQL Server Integration Services)**: Used to create the ETL pipeline.
- **SSMS (SQL Server Management Studio)**: Used to store and manage the data in the SQL Server database.
- **Power BI**: Used to create visualizations and dashboards to present the health data insights.
